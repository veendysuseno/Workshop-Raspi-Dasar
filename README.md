# Workshop Raspberry Pi (Basic)

Workshop **Raspberry Pi (Basic)** merupakan kegiatan pembelajaran yang membahas dasar-dasar **Raspberry Pi 3**, sistem operasi Linux, terminal Raspbian, serta implementasi bahasa pemrograman Python untuk mengendalikan komponen elektronika.

## 🎯 Capaian Pembelajaran

Setelah mengikuti workshop, peserta diharapkan mampu:

1. Memahami **board Raspberry Pi** dari sisi hardware dan software.
2. Memahami **sistem operasi Linux** dan penggunaan **Terminal Raspbian**.
3. Memahami fungsi dan implementasi **bahasa pemrograman Python** pada Raspberry Pi.

## 🛠️ Alat

1. Raspberry Pi 3
2. Buku / PDF Workshop
3. Trainer Workshop
4. PC / Laptop

## 💻 Perangkat Lunak

1. **PuTTY** — akses Raspberry Pi melalui SSH.
2. **VNC** — akses desktop Raspberry Pi secara remote.
3. **Python 3** — pemrograman dan implementasi sistem.
4. **Advanced IP Scanner / Zenmap** — identifikasi perangkat dan jaringan pada Desktop PC.
5. **Net Analyzer** — analisis jaringan melalui smartphone.

# 📚 Indeks Workshop

## BAB I — Pengenalan Raspberry Pi

### 1.1 Deskripsi Raspberry Pi
Pengenalan Raspberry Pi sebagai komputer mini berbasis single-board computer (SBC), fungsi, karakteristik, dan penggunaannya.

### 1.2 Jenis-Jenis Raspberry Pi
Mengenal berbagai jenis dan seri Raspberry Pi serta karakteristik penggunaannya.

### 1.3 Deskripsi Raspberry Pi OS
Pengenalan Raspberry Pi OS sebagai sistem operasi berbasis Linux yang digunakan pada Raspberry Pi.

### 1.4 Jenis-Jenis OS untuk Raspberry Pi
Mengenal berbagai sistem operasi yang dapat digunakan pada Raspberry Pi.

### 1.5 GPIO pada Raspberry Pi 3
Mempelajari **General Purpose Input/Output (GPIO)** pada Raspberry Pi 3 untuk berinteraksi dengan komponen elektronika.

### 1.6 Deskripsi SSH
Mempelajari **Secure Shell (SSH)** untuk mengakses Raspberry Pi secara remote melalui terminal.

### 1.7 Deskripsi VNC
Mempelajari **Virtual Network Computing (VNC)** untuk mengakses antarmuka desktop Raspberry Pi secara remote.

---

# 🐧 BAB II — Pengenalan Sistem Operasi Linux & Terminal Raspbian

### 2.1 Perintah Dasar Linux
Mempelajari perintah-perintah dasar Linux untuk melakukan navigasi dan pengelolaan sistem melalui terminal.

### 2.2 Headless Mode
Mempelajari penggunaan Raspberry Pi tanpa monitor, keyboard, atau mouse secara langsung dengan memanfaatkan koneksi jaringan dan akses remote.

### 2.3 Update & Upgrade
Mempelajari proses pembaruan sistem dan paket perangkat lunak pada Raspberry Pi.

### 2.4 Hak Akses File / Folder
Mempelajari permission pada Linux, termasuk hak akses terhadap file dan folder.

### 2.5 Manajemen Direktori pada Raspberry Pi 3 melalui VNC & SSH
Mempelajari pengelolaan direktori dan file menggunakan akses **VNC** maupun **SSH**.

---

# 🐍 BAB III — Pengenalan Fungsi & Implementasi Bahasa Pemrograman Python

### 3.1 Deskripsi Bahasa Python
Pengenalan bahasa pemrograman Python, karakteristik, serta penggunaannya pada Raspberry Pi.

### 3.2 Indentasi pada Bahasa Python
Mempelajari penggunaan indentasi sebagai bagian penting dari struktur program Python.

### 3.3 Perulangan pada Bahasa Python
Mempelajari konsep perulangan untuk menjalankan instruksi secara berulang menggunakan Python.

### 3.4 Kondisi pada Bahasa Python
Mempelajari penggunaan conditional statement untuk membuat program berdasarkan kondisi tertentu.

### 3.5 Operator Kondisi & Operator Logika pada Bahasa Python
Mempelajari operator perbandingan dan operator logika untuk membangun kondisi pada program Python.

### 3.6 Kendali Komponen Elektronika melalui Raspberry Pi 3 dengan Bahasa Python
Mengimplementasikan Python untuk mengendalikan komponen elektronika melalui **GPIO Raspberry Pi 3**.
